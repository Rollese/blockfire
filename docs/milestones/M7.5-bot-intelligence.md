# M7.5 — Bot Intelligence (Tactical AI)

**Status:** P2 engine merged + **128-bot fleet-gated ✅ (2026-07-01)** · **P3 support & survivability ✅ (2026-07-03)** · P1 (free-fly cam) partial · **P4 + operator visual sign-off remain** · **Blocked by:** M7 gate for the real (visual) gate.

**Objective:** replace the reflex "fight nearest enemy" bots with tactical, **human-like, fair-play** infantry AI good enough to backfill real 128-player matches alongside/against humans. Bots reason only from their interest-managed view (no omniscience), behave believably (reaction delay, imperfect aim), stay **anti-cheat-clean** (ordinary validated inputs; human-shaped distributions that don't trip Layer-4 — [ADR-0004](../adr/0004-anti-cheat-and-skill-matchmaking.md)). AI runs in the **bot-driver processes, off the 30 Hz server tick, out of `shared/`** — the budget is bot-driver CPU across the fleet, not the server step. **Full design-of-record: [`bot-ai.md`](../specs/bot-ai.md)** (5-layer architecture — perception/blackboard/commander/utility-decision/humanized-execution — behaviour catalog, `ai_tuning.json` difficulty profiles, spectator free-cam, constants, module layout).
