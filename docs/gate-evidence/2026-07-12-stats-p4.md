## What it proves (end to end)

game-server `StatsReporter` → ingest API → Postgres → `worker` rollup (`player_profiles`) →
`detect_anomalies` → `anomaly_flags` review queue → admin JSON/HTML triage. Plus the auth gate.

The `worker` is **stopped** before the anomaly-assertion phase so only the explicit
`POST /admin/api/anomaly/scan` calls mutate `anomaly_flags` — otherwise the periodic 30 s worker
cycle would race the assertions. A synthetic egregious-cheater `player_profiles` row is injected
directly (real bots in a short match won't reliably breach the floors; P4 must be *proven* to flag a
cheater), and detection is shown to be **discriminating** (only the cheater is flagged, not the whole
population).
