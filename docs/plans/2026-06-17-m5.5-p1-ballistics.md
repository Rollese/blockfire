# M5.5 Phase 1 — Ballistics & Weapon Handling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace hit-scan bullets with **stepped projectiles** (gravity drop + real travel time, dodgeable, lead-required), add **fire-mode selection** (auto/semi/burst), and add a **secondary weapon slot** (sidearm). All server-authoritative; the projectile integrator lives in `shared/sim/` so the M7 client can spawn a cosmetic predicted tracer from the same math.

**Architecture:** Bullets become a server-side **projectile pool** modelled exactly on the existing RPG rocket pool (`_rockets` / `_step_rockets` in `server_main.gd`): `_fire_shot` stops resolving an instant hit-scan ray and instead **spawns a projectile** `{owner, team, weapon_id, pos, vel, spawn_tick, dist, ttl}` with `vel = ray.dir * muzzle_velocity`; a new `_step_projectiles()` integrates each one per tick (`Projectile.integrate`, gravity scaled per weapon), raycasts the **segment** against the interest-grid broadphase (enemy hitboxes) + the structure store (penetration reuse), and calls the unchanged `_apply_pawn_damage` on a pawn hit. Lag-comp moves from per-shot rewind to **spawn-at-command-tick then present-time stepping** (travel masks latency). Fire-mode and weapon-swap are **CONTROL messages** (the input `buttons` byte is a full u8 — no free bits), mirroring the M4.5 `GADGET_ACTION` pattern; the per-client combat state grows a **two-slot weapon array** (primary + secondary) with independent ammo/reload.

**Tech Stack:** Godot 4.6 / GDScript. Tests `extends TestCase` under `tests/*_test.gd`, headless. Fleet gate via `docker/` on `game2` (14900KS — server pinned to P-cores `0-3`, AGENTS.md §8); ≤48-bot smoke via `ci/`.

**Scope:** Phase 1 of M5.5 only. Spec: [`docs/specs/combat-depth-2.md`](../specs/combat-depth-2.md) §1; milestone [`docs/milestones/M5.5-combat-depth-2.md`](../milestones/M5.5-combat-depth-2.md). P2 (armor/suppression) and P3 (melee/throwables) are separate plans. **Suppression's near-miss detection (P2) will hook into `_step_projectiles` — leave a clean seam there.**

```gdscript
class_name Projectile
extends Object
## Pure helpers for stepped bullet projectiles (M5.5-P1). A projectile is a plain dict held by the
## server pool; these are the deterministic math for its flight. Shared so the M7 client can spawn a
## cosmetic predicted tracer from the same integration. Nothing here touches networking. See
## docs/specs/combat-depth-2.md §1.

## Muzzle launch velocity for a unit look-direction at the weapon's muzzle speed.
static func initial_velocity(dir: Vector3, muzzle_velocity: float) -> Vector3:
	return dir.normalized() * muzzle_velocity

## One integration step. gravity_scale<1 = high-velocity round (little drop). Returns {pos, vel}.
static func integrate(pos: Vector3, vel: Vector3, gravity_scale: float, dt: float) -> Dictionary:
	var v := vel - Vector3(0.0, Grenade.GRAVITY * gravity_scale, 0.0) * dt
	return {"pos": pos + v * dt, "vel": v}

## A projectile expires when its lifetime is up OR it has flown past its weapon range.
static func expired(age_ticks: int, spawn_to_now: int, dist_traveled: float, max_range: float) -> bool:
	return age_ticks >= 0 and (spawn_to_now >= age_ticks or dist_traveled >= max_range)
```

> `expired` signature: caller passes `(ttl_ticks, ticks_since_spawn, dist, range)`. (Reusing `Grenade.GRAVITY` keeps one gravity constant across thrown + fired ordnance.)

```gdscript
func _step_projectiles() -> void:
	if _projectiles.size() > _proj_live_max:
		_proj_live_max = _projectiles.size()
	if _projectiles.is_empty():
		return
	var still: Array = []
	for pr in _projectiles:
		var wdef: Dictionary = pr["wdef"]
		var s := Projectile.integrate(pr["pos"], pr["vel"], float(wdef["gravity_scale"]), SimLoop.DT)
		var nxt: Vector3 = s["pos"]
		var seg: Vector3 = nxt - (pr["pos"] as Vector3)
		var seg_len := seg.length()
		var dir := (seg / seg_len) if seg_len > 0.0001 else Vector3(0,0,1)
		var max_range: float = float(wdef["range_m"])

		# Nearest enemy pawn along this segment (present-time positions; broadphase via grid).
		var best_t := seg_len + 1.0
		var best_victim := 0
		var best_head := false
		var candidates: Array = _grid.query(pr["pos"], seg_len + FIRE_RANGE_MARGIN, _positions)
		for tid in candidates:
			if tid == int(pr["owner"]): continue
			var v: Pawn = _sim.world.get_pawn(tid)
			if v == null or not v.alive or v.team == int(pr["team"]): continue
			var hit := Hitbox.raycast_pawn(pr["pos"], dir, v.pos, v.stance, seg_len)
			if hit["hit"] and hit["t"] < best_t:
				best_t = hit["t"]; best_victim = tid; best_head = hit["headshot"]

		# Structure interposed nearer than the pawn -> penetration / stop (M4.5 reuse).
		var enemy_dmg := Combat.damage_for(int(pr["weapon_id"]), best_head, float(pr["dist"]) + best_t, wdef) if best_victim != 0 else 0
		var body_dmg := int(wdef["damage_body"])
		if _store.count() > 0 and seg_len > 0.0001:
			var march_max: float = best_t if best_victim != 0 else seg_len
			var blocked := _store.march(pr["pos"], dir, march_max)
			if blocked["hit"] and float(blocked["dist"]) < best_t:
				var rec: Dictionary = _store.get_record(int(blocked["id"]))
				if rec.is_empty(): continue
				var mat := _catalog.material_of(int(rec["type"]))
				if not PieceCatalog.is_penetrable(mat):
					_damage_structure(int(blocked["id"]), body_dmg)
					continue   # bullet stops
				var split := Combat.apply_penetration(body_dmg, enemy_dmg, PieceCatalog.absorption_of(mat), PieceCatalog.transmit_of(mat))
				_damage_structure(int(blocked["id"]), int(split["piece_damage"]))
				if _store.get_record(int(blocked["id"])).is_empty(): continue   # 1-pen consumed
				if best_victim == 0: continue
				_pen += 1
				enemy_dmg = int(split["exit_damage"])

		if best_victim != 0 and enemy_dmg > 0:
			var victim: Pawn = _sim.world.get_pawn(best_victim)
			if victim != null and victim.alive:
				_proj_hits += 1; _hits += 1
				_apply_pawn_damage(best_victim, victim, enemy_dmg, best_head, Revive.Source.BULLET, int(pr["owner"]), int(pr["weapon_id"]))
				var sc: Dictionary = _clients.get(int(pr["owner"]), {})
				if not sc.is_empty() and not sc.get("auto_deploy", true):
					var lethal: bool = (not victim.alive) or victim.is_downed
					_net.send_to(sc["peer"], NetHost.CHANNEL_CONTROL, Protocol.encode_hitmarker(best_head, lethal), 0)
			continue   # bullet consumed by the pawn hit

		# Miss this step: advance, age, expire.
		pr["pos"] = nxt; pr["vel"] = s["vel"]; pr["dist"] = float(pr["dist"]) + seg_len
		if nxt.y <= 0.0: continue   # hit the ground -> gone
		if Projectile.expired(int(pr["ttl"]), _sim.tick - int(pr["spawn_tick"]), float(pr["dist"]), max_range): continue
		still.append(pr)
	_projectiles = still
```
