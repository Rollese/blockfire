# M5.5 Phase 3 — Melee & Throwables Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add **melee** (universal quick-knife with rear-arc instant-kill back-stab + an Engineer-only **sledgehammer** for fast structure demolition) and two new throwables — **flashbang** (LOS-gated blind/deafen) and **impact grenade** (zero-fuse, detonates on contact).

**Architecture:** A new pure `shared/sim/melee.gd` holds the range + rear-arc back-stab geometry; a `MELEE` CONTROL message (the input `buttons` byte is full) triggers a server-side resolve against the nearest enemy (knife) or the targeted structure cell (sledgehammer, reusing the M4 `_damage_structure` path). Flashbang and impact extend the existing thrown-grenade pool (`_grenades` / `_step_grenades` / `_detonate` in `server_main.gd`) with two new `Grenade` type constants: impact detonates on first contact (march like the RPG rocket); flashbang's `_detonate` branch blinds enemies in radius **with line-of-sight** (reuse `_store.march` for occlusion) by setting `Pawn.blind_until_tick`, replicated as one byte for the M7 white-out.

**Tech Stack:** Godot 4.6 / GDScript. Tests `extends TestCase`, headless. Fleet gate via `docker/` on `game2` (server P-cores `0-3`); ≤48 smoke via `ci/`.

**Scope:** Phase 3 of M5.5 (final phase). Builds on M4's grenade pool + structure-damage path and M4.5's instant-kill bypass. Spec: [`docs/specs/combat-depth-2.md`](../../specs/combat-depth-2.md) §3; milestone [`M5.5-combat-depth-2.md`](../../milestones/M5.5-combat-depth-2.md).

```gdscript
class_name Melee
extends Object
## Pure melee geometry (M5.5-P3): reach + rear-arc back-stab + nearest-target selection.
## Server applies damage; these are side-effect-free. See spec §3.

const MELEE_RANGE := 1.5
const BACKSTAB_ARC_DEG := 60.0

static func in_reach(attacker_pos: Vector3, target_pos: Vector3) -> bool:
	return attacker_pos.distance_to(target_pos) <= MELEE_RANGE

## `rel` is (attacker_pos - target_pos): where the attacker stands relative to the target. A
## back-stab requires the attacker to be within BACKSTAB_ARC of directly behind the target's facing.
static func is_backstab(target_yaw: float, rel: Vector3) -> bool:
	var back := Vector3(-sin(target_yaw), 0.0, -cos(target_yaw))   # opposite the target's forward
	var flat := Vector3(rel.x, 0.0, rel.z)
	if flat.length() < 0.001:
		return false
	return rad_to_deg(back.angle_to(flat.normalized())) <= BACKSTAB_ARC_DEG * 0.5

## Nearest enemy within reach and within a frontal cone of the attacker; 0 if none.
static func best_target(attacker: Dictionary, enemies: Array) -> int:
	var fwd := Vector3(sin(attacker["yaw"]), 0.0, cos(attacker["yaw"]))
	var best := 0
	var best_d := MELEE_RANGE + 1.0
	for e in enemies:
		if int(e["team"]) == int(attacker["team"]):
			continue
		var to: Vector3 = e["pos"] - attacker["pos"]
		var d := to.length()
		if d > MELEE_RANGE or d < 0.001:
			continue
		if Vector3(to.x,0,to.z).normalized().dot(fwd) < 0.3:   # not in front
			continue
		if d < best_d:
			best_d = d; best = int(e["id"])
	return best
```

- [ ] **Step 5: Server resolve** — add `_resolve_melee(id)` called from the CONTROL dispatch on `Msg.MELEE`, with a `MELEE_COOLDOWN_TICKS` gate per client (`c["melee_ready_tick"]`). Knife path (all classes): build the enemy list from `_grid.query` near the attacker, pick `Melee.best_target`, and on hit apply damage — **back-stab = instant kill** (bypass DBNO like a headshot), else `MELEE_DAMAGE` via `_apply_pawn_damage`:

```gdscript
func _resolve_melee(id: int) -> void:
	var c = _clients[id]
	if _sim.tick < int(c.get("melee_ready_tick", 0)): return
	c["melee_ready_tick"] = _sim.tick + MELEE_COOLDOWN_TICKS
	var atk: Pawn = _sim.world.get_pawn(id)
	if atk == null or not atk.alive: return
	# Sledgehammer (Engineer) hits structures first — see Task 4. Knife otherwise:
	var enemies: Array = []
	for tid in _grid.query(atk.pos, Melee.MELEE_RANGE + 1.0, _positions):
		var v: Pawn = _sim.world.get_pawn(tid)
		if v != null and v.alive and v.team != atk.team:
			enemies.append({"id": tid, "pos": v.pos, "team": v.team})
	var vid := Melee.best_target({"pos": atk.pos, "yaw": atk.yaw, "team": atk.team}, enemies)
	if vid == 0: return
	var victim: Pawn = _sim.world.get_pawn(vid)
	var rel := atk.pos - victim.pos
	if Melee.is_backstab(victim.yaw, rel):
		_apply_pawn_damage(vid, victim, 100000, true, Revive.Source.BULLET, id, _clients[id]["weapon"])  # instakill (headshot=true bypasses DBNO)
		_backstabs += 1
	else:
		_apply_pawn_damage(vid, victim, MELEE_DAMAGE, false, Revive.Source.BULLET, id, _clients[id]["weapon"])
	_melees += 1
```

```gdscript
func _detonate_flash(g: Dictionary) -> void:
	_flashes += 1
	var center: Vector3 = g["pos"]
	for id in _sim.world.pawns:
		var p: Pawn = _sim.world.pawns[id]
		if not p.alive: continue
		var to: Vector3 = p.eye_position() - center
		var d := to.length()
		if d > FLASH_RADIUS or d < 0.001: continue
		# LOS: a solid structure strictly between the blast and the eye blocks the flash.
		if _store.count() > 0 and bool(_store.march(center, to / d, d)["hit"]): continue
		p.blind_until_tick = maxi(p.blind_until_tick, _sim.tick + FLASH_BLIND_TICKS)
		_flash_blinds += 1
```
