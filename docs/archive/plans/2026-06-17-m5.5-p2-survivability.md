# M5.5 Phase 2 — Survivability (Armor Class + Suppression) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a **simplified armor class** (LIGHT / MEDIUM / HEAVY) bundling body damage-reduction + move-speed penalty + ammo/throwable capacity (helmet folded into the tier), and a **gameplay-affecting suppression** mechanic (incoming near-misses raise the suppressed pawn's effective spread + aim-sway).

**Architecture:** Two pure helper modules — `shared/sim/armor.gd` (per-class multipliers, headshot-lethality rule) and `shared/sim/suppress.gd` (accrue/decay math) — hold the side-effect-free rules and are unit-tested in isolation. `Pawn` gains `armor_class` (drives `Armor.speed_mult` in `step()`) and `suppression` (a 0..1 scalar). Damage application in `_apply_pawn_damage` multiplies body damage by `Armor.body_mult` and routes a sub-threshold headshot to body-damage for HEAVY (helmet). Suppression accrues in `_step_projectiles` (the seam left by P1: an enemy bullet passing within `SUPPRESS_RADIUS` but not hitting) and decays each tick; while above `SUPPRESS_THRESHOLD` it is fed into `Combat.reconstruct_ray` to widen spread. `suppression` is replicated as one quantized byte for the M7 screen FX.

**Tech Stack:** Godot 4.6 / GDScript. Tests `extends TestCase`, headless. Fleet gate via `docker/` on `game2` (server pinned P-cores `0-3`); ≤48 smoke via `ci/`.

**Scope:** Phase 2 of M5.5. **Depends on P1** (projectile pool — suppression near-miss detection hooks into `_step_projectiles`). Spec: [`docs/specs/combat-depth-2.md`](../specs/combat-depth-2.md) §2; milestone [`M5.5-combat-depth-2.md`](../milestones/M5.5-combat-depth-2.md).

```gdscript
class_name Armor
extends Object
## Simplified loadout armor: one class bundles body damage-reduction + move-speed + (implicit)
## helmet headshot protection. Pure rules; data here keeps the damage equation in one place.
## See docs/specs/combat-depth-2.md §2.

const LIGHT := 0
const MEDIUM := 1
const HEAVY := 2

const _BODY_MULT := {LIGHT: 1.0, MEDIUM: 0.85, HEAVY: 0.7}
const _SPEED_MULT := {LIGHT: 1.0, MEDIUM: 0.95, HEAVY: 0.9}

static func body_mult(cls: int) -> float:
	return float(_BODY_MULT.get(cls, 1.0))

static func speed_mult(cls: int) -> float:
	return float(_SPEED_MULT.get(cls, 1.0))

## A headshot of `head_dmg` (already incl. headshot mult, pre-armor) is an instant kill unless a
## HEAVY helmet absorbs enough that it no longer meets/exceeds current HP. LIGHT/MEDIUM never save.
static func headshot_lethal(cls: int, head_dmg: int, hp: int) -> bool:
	if cls != HEAVY:
		return head_dmg >= hp
	return int(round(float(head_dmg) * body_mult(HEAVY))) >= hp
```

And in `loadout.gd`:

```gdscript
static func armor_for(cls: int) -> int:
	match cls:
		RECON: return Armor.LIGHT      # scout mobility
		SUPPORT, ENGINEER: return Armor.HEAVY
		_: return Armor.MEDIUM         # assault/medic
```

```gdscript
class_name Suppress
extends Object
## Pure suppression math (M5.5-P2). A 0..1 scalar per pawn raised by nearby incoming fire and
## decaying each tick; above a threshold it widens the pawn's shot spread. See spec §2.

const SUPPRESS_RADIUS := 2.5
const SUPPRESS_PER_NEARMISS := 0.15
const SUPPRESS_DECAY := 0.04
const SUPPRESS_THRESHOLD := 0.25
const MAX_SPREAD_DEG := 2.5

## Add suppression for a near-miss at `dist` metres (closer = more), clamped to [0,1].
static func accrue(current: float, dist: float) -> float:
	if dist >= SUPPRESS_RADIUS:
		return current
	var closeness := 1.0 - (dist / SUPPRESS_RADIUS)
	return clampf(current + SUPPRESS_PER_NEARMISS * closeness, 0.0, 1.0)

static func decay(current: float) -> float:
	return maxf(0.0, current - SUPPRESS_DECAY)

## Extra spread in degrees from the current suppression (0 below threshold; ramps to MAX at 1.0).
static func spread_penalty_deg(suppression: float) -> float:
	if suppression < SUPPRESS_THRESHOLD:
		return 0.0
	var t := (suppression - SUPPRESS_THRESHOLD) / (1.0 - SUPPRESS_THRESHOLD)
	return MAX_SPREAD_DEG * clampf(t, 0.0, 1.0)
```
